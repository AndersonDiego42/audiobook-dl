[bold]Basic usage[/bold]
audiobook-dl \[options] <url>
audiobook-dl \[options] -c <cookie_file> <url>

[bold]Common options[/bold]
 • --list-sources          List all supported audiobook services
 • --search / --library-list Search or list books from supported services
 • --verify-auth           Test service credentials without downloading
 • --info / --dry-run      Inspect metadata and output path without downloading
 • --series-items 1,3-5    Download selected items from a series or shelf
 • --resume                Resume interrupted downloads via HTTP Range
 • --download-archive FILE Skip books already recorded in SQLite archive
 • -y / --overwrite        Overwrite existing outputs without prompting
 • -f <fmt> --combine      Convert/combine into a single .m4b / .mp3 file
 • --split-chapters        Split audiobook output into one file per chapter
 • --output-preset NAME    Output naming preset (default, audiobookshelf, plex, kavita)
 • --check-updates         Check if a newer release is available

[bold]Description[/bold]
audiobook-dl downloads audiobooks from supported providers. Settings and
saved credentials can be managed in audiobook-dl.toml or audiobook-dl-gui.
For full flag details run:
 • audiobook-dl --help
 • https://github.com/jo1gi/audiobook-dl
